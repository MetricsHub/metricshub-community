# Provenance

The `.proto` files in this directory are vendored from the official OpAMP specification:

- Repository: https://github.com/open-telemetry/opamp-spec
- Tag: `v0.19.0`
- Commit: `c55ef2474d371b301b522266239f87dcc8cdebd6`
- Files: `proto/opamp/v1/opamp.proto`, `proto/opamp/v1/anyvalue.proto`
- License: Apache-2.0 (upstream headers preserved)

## Local modifications

Both files carry a single MetricsHub delta, which is wire-format neutral:

```proto
option java_package = "org.metricshub.opamp.proto";
option java_multiple_files = true;
option java_outer_classname = "AnyValueProto"; // "OpampProto" in opamp.proto
```

The explicit `java_outer_classname` avoids a case-insensitive filename collision on Windows
between the default outer class (`Anyvalue`) and the `AnyValue` message.

## Updating

1. Download the two files from a newer `open-telemetry/opamp-spec` tag into this directory.
2. Re-apply the `java_package` / `java_multiple_files` options after the upstream `option` lines.
3. Update the tag/commit above.
4. Rebuild (`mvn -pl metricshub-opamp-client verify`) — Java sources are regenerated by
   `protobuf-maven-plugin`; nothing generated is committed.
